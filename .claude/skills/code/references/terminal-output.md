# Terminal Output Style Guide

## 원칙

터미널 출력(print)은 학생이 실행 상태를 한눈에 파악할 수 있도록 이모지와 구분선을 적극 사용한다.

## 이모지 카테고리

### 상태 표시

| 이모지 | 용도 | 예시 |
|--------|------|------|
| ✅ | 성공/완료 | `✅ 파이프라인 완료` |
| ❌ | 실패/오류 | `❌ 모델 로드 실패` |
| ⚠️ | 경고/주의 | `⚠️ ChromaDB가 비어 있습니다` |
| ⏳ | 진행 중/로딩 | `⏳ 임베딩 모델 로드 중...` |
| 💡 | 팁/안내 | `💡 종료: quit / exit` |

### 데이터/파일

| 이모지 | 용도 | 예시 |
|--------|------|------|
| 📁 | 디렉토리/경로 | `📁 ChromaDB: ./data/chroma_db` |
| 📄 | 텍스트 문서 | `📄 출처: HR_취업규칙.pdf` |
| 📦 | 컬렉션/패키지 | `📦 컬렉션: metacoding_documents` |
| 🖼️ | 이미지/차트 | `🖼️ 캡처본: assets/chart.png` |

### 검색/분석

| 이모지 | 용도 | 예시 |
|--------|------|------|
| 🔍 | 검색 쿼리 | `🔍 검색 쿼리: 연차 사용 규정` |
| 📊 | 통계/결과 수 | `📊 상위 3개 결과를 검색합니다` |
| 🥇🥈🥉 | 순위 1~3위 | 검색 결과 랭킹 |
| 🟢🟡🔴 | 점수 수준 (높음/중간/낮음) | 유사도, 정확도 등 |

### 실행 단계

| 이모지 | 용도 | 예시 |
|--------|------|------|
| 🚀 | 시작/실행 | `🚀 파이프라인 시작` |
| 🔧 | 설정/초기화 | `🔧 ChromaDB 초기화` |
| 📝 | 파싱/추출 | `📝 문서 텍스트 추출 중...` |
| ✂️ | 청킹/분할 | `✂️ 청킹 중... (500자, 100자 오버랩)` |
| 🧮 | 임베딩/계산 | `🧮 임베딩 계산 중... 17개 벡터` |
| 💾 | 저장 | `💾 ChromaDB 저장 완료` |

## 구분선

```python
SEPARATOR = "=" * 60       # 섹션 구분 (굵은 선)
LINE = "─" * 60            # 결과 항목 구분 (가는 선)
```

## 프로그레스 바

점수나 진행률을 시각적으로 표시할 때 블록 문자를 사용한다.

```python
def progress_bar(pct: float, width: int = 20) -> str:
    filled = int(pct / 100 * width)
    return "█" * filled + "░" * (width - filled)

# 출력 예: 🟡 유사도 78.0%  ███████████████░░░░░
```

## 적용 범위

- `main.py`, `cli_search.py` 등 학생이 터미널에서 직접 실행하는 스크립트에 적용한다.
- 라이브러리 모듈(`extractor.py`, `store.py` 등)의 내부 print에는 이모지를 사용하지 않는다.
- 이모지는 print() 문자열에만 사용하며, 로그 파일 출력에는 사용하지 않는다.
