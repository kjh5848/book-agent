# 집필 스킬 (Writing)

## 핵심 규칙 요약

- 어조: 하십시오체 (~합니다, ~입니다), 추측성 표현 금지
- 볼딩: `**용어**` 앞뒤 공백 필수
- 이모지: 본문 사용 금지
- 구조: 모든 챕터는 `## N. 정리하며`로 마무리
- 코드 블록 아래: 반드시 `#### 코드 워크플로우 (Code Workflow)` 배치
- 실습: GitHub Clone 방식 — 독자는 코드를 타이핑하지 않음

## 참조 파일

작업 전 필요한 파일을 읽으십시오:

| 파일 | 로드 시점 |
|------|---------|
| `references/style.md` | 항상 |
| `references/chapter-structure.md` | 챕터 집필 시 |
| `references/box-style.md` | 팁/경고 박스 삽입 시 |
