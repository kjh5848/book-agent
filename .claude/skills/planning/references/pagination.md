# 분량 관리 규칙

## 1. 절대 제약

- **총 페이지**: 100페이지 이하 (절대 불가침)
- **단일 챕터**: 20페이지 이하
- **목표 초과 절대 불가**

## 2. 페이지 배분 매트릭스

```text
[Part 1. 기본기] CH01 (Xp) / CH02 (Xp)
[Part 2. 실습]  CH03 (Xp) / CH04 (Xp)
[부록]          에러 가이드 (Xp)
합계: 100p 이하
```

## 3. 챕터 내 구성 비율

각 챕터 내에서 아래 비율을 참고합니다:

| 구성 요소 | 비율 | 예시 (10p 챕터) |
|----------|------|----------------|
| 도입 | 10% | 1p |
| 개념 설명 | 20% | 2p |
| 코드 실습 | 50% | 5p |
| 심화/에러대응 | 10% | 1p |
| 정리하며 | 10% | 1p |

## 4. 이론 vs 실습 비율

- **기본 비율**: 이론 30%, 실습 70%
- 입문자 대상: 이론 40%, 실습 60%
- 고급자 대상: 이론 20%, 실습 80%

## 5. 페이지 산정 기준

- 마크다운 기준 약 40줄 = 1페이지
- 코드 블록 포함 시 코드 라인도 포함하여 산정
- Mermaid 다이어그램 = 약 0.5페이지
- 이미지 = 약 0.5~1페이지

## 6. 목차 검증 체크리스트

- [ ] 챕터 수 × 평균 페이지가 100페이지 이하인가
- [ ] 도입부 → 심화 순서로 학습 곡선이 자연스러운가
- [ ] 각 챕터가 단독으로도 의미가 있는가
- [ ] 첫 챕터에서 독자가 실행 결과를 볼 수 있는가 (조기 성취감)
