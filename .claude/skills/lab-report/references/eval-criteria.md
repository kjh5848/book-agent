# Evaluation Criteria for Students

<!-- 실습 보고서의 종합 평가에서 아래 4가지 항목을 5점 만점으로 평가한다. -->

Evaluate the following 4 items on a 5-point scale in the overall evaluation of the lab report.

---

## 1. Setup Difficulty
<!-- 환경 설정 난이도 -->

Score is assigned by inversely measuring how much difficulty the student experienced in setting up the environment.
(Higher difficulty = lower score)

| Score | Criteria |
|-------|----------|
| 5 | Completed without errors by following the README as-is |
| 4 | 1 minor error, easily resolved |
| 3 | 2–3 errors, resolvable without external references |
| 2 | Multiple errors, external reference materials required |
| 1 | Environment setup was impossible or README was inadequate |

---

## 2. Run Success Rate
<!-- 실행 성공률 -->

The proportion of successful steps out of all lab steps.

| Score | Criteria |
|-------|----------|
| 5 | 100% success |
| 4 | 80% or more success |
| 3 | 60% or more success |
| 2 | 40% or more success |
| 1 | Less than 40% success |

---

## 3. Code Comprehensibility
<!-- 코드 이해도 -->

Evaluate whether readers can read and understand the code.

| Score | Criteria |
|-------|----------|
| 5 | Docstrings, comments, and variable names are all clear; understandable without explanation |
| 4 | Mostly clear, but some complex parts exist |
| 3 | Core logic is understandable, but detailed implementation is difficult |
| 2 | Insufficient comments and unclear variable names make comprehension difficult |
| 1 | Cannot be understood from code alone |

---

## 4. Documentation Quality
<!-- 문서화 품질 -->

Completeness of README, .env.example, and execution scenarios.

| Score | Criteria |
|-------|----------|
| 5 | README contains all information including expected output |
| 4 | Most information included, some omissions |
| 3 | Basic execution instructions exist, but detailed explanation is lacking |
| 2 | README is incomplete, important information is missing |
| 1 | README is nearly absent or content is insufficient |

---

## Overall Judgment Criteria
<!-- 종합 판정 기준 -->

| Total Score | Judgment |
|-------------|----------|
| 18–20 | EXCELLENT — Reader-friendly completeness |
| 14–17 | GOOD — Sufficiently practical |
| 10–13 | FAIR — Some improvements needed |
| 6–9 | POOR — Significant improvements required |
| 5 or below | FAIL — Not suitable for practice |
