# 시각 스킬 (Visual)

## 핵심 규칙 요약

- Mermaid: `flowchart` 키워드, 노드 7개 이하
- 특수문자 포함 레이블: 반드시 쌍따옴표 (`A["텍스트(예시)"]`)
- 연결선 텍스트: `A -- "텍스트" --> B` 형식 필수
- 볼드/이탤릭(`**`, `*`): Mermaid 내부 절대 사용 금지
- 이미지: 흑백 라인아트, 16:9, 캡션 `*그림 {장}-{순번}: 설명*`

## 참조 파일

| 파일 | 로드 시점 |
|------|---------|
| `references/mermaid.md` | Mermaid 다이어그램 작성 시 |
| `references/image.md` | 이미지 생성/삽입 시 |
