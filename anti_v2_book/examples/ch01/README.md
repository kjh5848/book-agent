# 🚀 CH01. 기초 RAG 실습: 로컬 LLM 단독 구동 테스트

이 폴더는 책의 **Chapter 1**에 해당하는 실습 예제입니다. 
아직 RAG(검색 증강 생성) 시스템을 도입하기 전, 그저 평범한 로컬 LLM(DeepSeek R1)에게 우리 회사만의 비밀(?)인 "하계 휴가 지원금 정책"을 물어보았을 때 어떤 대답을 하는지 체험해 보는 코드입니다.

## 🎯 목표
1. 내 컴퓨터(로컬)에서 파이썬과 Ollama가 정상적으로 대화(API 호출)할 수 있는지 확인합니다.
2. AI가 사내 지식을 학습하지 않았을 때 발생하는 **그럴싸한 거짓말(Hallucination)**을 직접 두 눈으로 확인합니다.


```bash
python 01_basic_llm.py
```
