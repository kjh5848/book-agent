# CH03. 지능형 브레인: MCP 에이전트 통합 — 집필 플랜 (chapter_plan)

## 1. 챕터 목표

이 챕터의 독자는, 읽고 나서 다음 질문에 스스로 답할 수 있어야 합니다.
- "정형(DB) 데이터와 비정형(문서) 데이터를 AI가 어떻게 함께 다루는가?"
- "MCP(Multi-Context Pipeline) 기반의 라우팅이란 무엇인가?"

## 2. 세부 목차 (Section)

| 절 | 제목 | 분량 |
|---|---|---|
| 3.1 | 정형 데이터의 세계 (PostgreSQL 사내 DB 연동 및 기초 쿼리) | 8p |
| 3.2 | 에이전트의 뇌 설계: 사용자의 질문은 어디로 가야 할까? (라우팅 알고리즘) | 12p |
| 3.3 | 정형(MCP)과 비정형(RAG)을 엮어내는 통합 AI 브레인 완성 | 12p |
| 3.4 | AI 채팅 UI 연동 및 엔드투엔드(End-to-End) 테스트 | 8p |

## 3. 핵심 개념 및 다이어그램 계획

- **[Type A 다이어그램]** 사용자 질문 → 라우터 → (RAG 경로 / MCP 경로) 분기 → 통합 컨텍스트 → 최종 답변 아키텍처 (Mermaid)
- **[Type B 이미지 프롬프트]** "라우터를 도서관 사서에 비유: 문서 창고(RAG) vs 엑셀 장부(DB) 중 어디서 가져올지 선택"
