# CH02. 사내 지식 검색 엔진 구축 — 집필 플랜 (chapter_plan)

## 1. 챕터 목표

이 챕터의 독자는, 읽고 나서 다음 질문에 스스로 답할 수 있어야 합니다.
- "PDF에서 텍스트와 표를 어떻게 구분하여 추출하는가?"
- "벡터 DB(ChromaDB)에 문서를 어떻게 저장하고 검색하는가?"
- "RAG 기반 Q&A 봇은 어떻게 만드는가?"

## 2. 세부 목차 (Section)

| 절 | 제목 | 분량 |
|---|---|---|
| 2.1 | 실습 환경 완벽 세팅 (Python 가상환경, 의존성 패키지 관리) | 4p |
| 2.2 | 사내 문서 수집 및 텍스트 전처리 가이드라인 (기본 파싱) | 6p |
| 2.3 | **[고도화] 복잡한 PDF 내 표(Table) 데이터 추출 및 파싱 심화** | 8p |
| 2.4 | 텍스트 쪼개기(Chunking)와 벡터 임베딩 베이스 (ChromaDB 연동) | 7p |
| 2.5 | LangChain 기반 사내 Q&A 봇 1차 완성 (출처 표기 기법 포함) | 5p |

## 3. 핵심 개념 및 다이어그램 계획

- **[Type A 다이어그램]** PDF → 파싱 → Chunking → Embedding → VectorDB → 검색(Retrieve) → 프롬프트 → 답변 흐름도 (Mermaid)
- **[Type B 이미지 프롬프트]** "표(Table) 데이터가 일반 텍스트로 뭉개지는 샌드위치 레이어 구조" 비유
