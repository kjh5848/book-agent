# IPO(Input-Process-Output) 모듈화 패턴 규칙

본문 실습 코드를 작성할 때, `main.py` 안에 수 백 줄을 한 번에 때려 넣는 방식은 독자를 지치게 만듭니다. 구조를 항상 **I(입력) - P(처리) - O(출력)** 로 쪼개서 블록 단위로 설계하십시오.

### 1. 단계별 모듈화
- 코드를 작성할 때 기능별로 함수를 분리하십시오.
  - 예: `1_load_data()`, `2_process_logic()`, `3_save_result()`
- 본문에서 코드를 설명할 때 이 단계들을 차례대로 보여줍니다.

### 2. 시연 가능성 (Reproducibility)
- 독자가 제공된 코드를 복사해서 붙여넣었을 때 **수정 없이 바로 구동**되는 것을 목표로 합니다.
- 파일 경로나 API Key 같은 환경 변수가 필요하면 코드 내에 하드코딩하지 말고 `.env` 를 쓰거나 "이 부분에 본인의 키를 넣으세요"라고 한국어 주석으로 명확히 안내하십시오.
