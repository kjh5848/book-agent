# 단일 챕터(Chapter) 구조화 규칙

하나의 챕터 마크다운 파일(예: `CH01_concept.md`)을 작성할 때는 항상 아래의 3단계 뼈대를 지켜서 작성합니다. 갑자기 코드부터 들이밀지 마십시오.

### 서론: 이번 장에서 배울 내용 (15%)
- 챕터의 목표를 3줄 요약.
- (선택) 여기서 `book_visual` 의 Type A (Mermaid 아키텍처 다이어그램)를 삽입하여 앞으로 만들 결과물의 청사진을 보여줌.

### 본론: 개념 및 실습 코딩 (70%)
- 이론 설명: 어려운 내용은 `book_visual` 의 Type B (보조 이미지)를 삽입해 설명함.
- 코드 작성: 코드를 블록 단위로 쪼개어 설명(`book_code_*` 의 IPO 패턴 등 활용).
- 결과 확인: 코드가 완성된 직후, `book_visual` 의 Type C (터미널/브라우저 성공 결과물 캡처)를 삽입해 독자가 맞게 따라왔는지 검증해 줌.

### 결론: 요약 및 다음 장 예고 (15%)
- 이번 장에서 다룬 핵심 키워드 3가지 리뷰.
- 다음 장에서 배울 내용에 대한 짧은 떡밥(Teaser) 투척.
