# 안티그래비티 레고 블록식 스킬 세트 (Registry)

집필 파이프라인(마스터 워크플로우) 수행 시, 안티그래비티는 특정 스킬 문서를 상황에 맞게 로드하여 사용합니다. 각 스킬 폴더 내 `references/` 경로에는 해당 도메인의 핵심 원칙들이 담겨 있습니다.

## 스킬 그룹 분류
1. **book_planning**: 도서 기획(100장 분량 계산, 타겟 독자 설정 등) 지식
2. **book_writing**: 문체, 테크 라이터 페르소나, 챕터 구성 지식
3. **book_visual**: 아키텍처 다이어그램 및 캡처 삽입 3대 지식
4. **book_code_python**: 파이썬 전용 코딩 컨벤션 및 에러 검증 지식
   - *자바 등 타 언어 집필 시 `book_code_java` 등으로 교체 사용 가능*
5. **book_verification**: 최종 집필 검수 및 오탈자/포맷팅 룰 지식

위 카테고리(폴더) 내부의 `SKILL.md` 와 보조 문서들을 찾아 읽으면 특정 분야의 도메인 지식을 얻을 수 있습니다.
