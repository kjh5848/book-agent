# Mermaid 다이어그램 작성 규칙

본문에 흐름도나 아키텍처 다이어그램(Type A)을 그릴 때, Mermaid 코드 블록을 사용합니다.
이때 **안티그래비티전용 Mermaid 렌더링 호환성**을 위해 다음 규칙을 최우선으로 지킵니다.

1. **쌍따옴표 강제 이스케이프 (`""`) 및 마크다운(`**`) 금지**
   다이어그램의 텍스트 레이블 내에 괄호 `()`나 특수기호를 사용할 경우, 렌더링 에러를 막기 위해 **텍스트 전체를 쌍따옴표 `""`로 감싸야 합니다**. 
   또한, 쌍따옴표 내부 혹은 외부에 볼드체(`**`), 이탤릭체(`*`) 등의 **마크다운 포맷팅 기호를 절대 사용하지 마십시오.** (Parse Error의 주 원인)
   - 올바른 예시: `subgraph step1 ["Step 1: LLM 단독 실행 (오류)"]`
   - 잘못된 예시: `subgraph step1 [**"Step 1: LLM 단독 실행 (오류)"**]`

2. **단순함 유지**
   너무 복잡한 `graph TD`나 난해한 구조를 피하고, 독자가 컴포넌트 간의 상호작용(예: DB -> API -> Client)을 한 눈에 직관적으로 파악할 수 있는 수준으로만 작성하세요.

3. **테마 호환성**
   별도의 `classDef` 컬러 값을 하드코딩할 경우 다크테마나 라이트테마에서 글자가 안 보이지 않도록 `fill` 배경색을 밝고 연한 파스텔 톤 계열로, `color` 속성을 검정색(`#000`)으로 명확히 고정해 주십시오.
