# 최종 검증 공통 룰

Phase 4 작성이 완료된 후 사용자에게 보고하기 전, 스스로 작성한 `[프로젝트_출력_루트]/chapters/` (예: `anti_v2_book/chapters/`) 하위 파일들을 모두 열어 다음 항목을 검증하십시오.

1. **톤앤매너 체크**: 본문 전체에 `입니다/합시다` 체가 쓰였는지 (반말이 튀어나왔는지) 검사.
2. **띄어쓰기 글로벌 룰 체크**: `**굵은글씨**` 또는 `**"쌍따옴표텍스트"**` 의 바로 뒤에 띄어쓰기(공백) 1칸이 잘 보장되어 있는지 정규식 수준으로 철저검증.
3. **에셋 링크 깨짐 여부**: `![캡션](../../assets/CH01_...png)` 링크 경로가 올바른지 체크.
4. **결과 없는 실습**: 코드 스니펫만 나열하고 그 뒷부분에 구동 성공 캡처 화면(Type C)이나 터미널 출력 요약이 빠져 있는 곳은 없는지 확인.
