# 법인세 프로그램 기술서 — 초안

## 기본 정보

- **주제**: 법인세 계산 프로그램 만들기
- **대상 독자**: 초급 (프로그래밍 입문자, 세무/회계 비전공자 포함)
- **핵심 기술 스택**: Python 3.11+, pandas, Streamlit, openpyxl
- **예상 챕터 수**: 10개
- **특별 요구 사항**: 없음 (일반적인 법인세 계산 프로그램 구현에 집중)

## 기술 스택 상세

| 구분 | 기술 | 용도 |
|------|------|------|
| 언어 | Python 3.11+ | 메인 개발 언어 |
| 데이터 처리 | pandas | 재무 데이터 가공, 집계 |
| 엑셀 입출력 | openpyxl | 엑셀 파일 읽기/쓰기 |
| 웹 UI | Streamlit | 법인세 계산기 웹 인터페이스 |
| PDF 생성 | fpdf2 | 신고서/보고서 PDF 출력 |
| 테스트 | pytest | 계산 로직 단위 테스트 |

## 챕터 구성 (안)

### CH01: 이 책의 목표와 완성본 미리보기
- 최종 완성될 법인세 계산 프로그램 데모
- 책의 학습 로드맵
- 법인세 프로그램이 왜 필요한가

### CH02: 개발 환경 구축
- Python 설치 및 가상환경 설정
- 필요 패키지 설치 (pandas, streamlit, openpyxl)
- VS Code 설정 및 프로젝트 구조 만들기

### CH03: 법인세 기초 이해
- 법인세란 무엇인가 (세율 구조, 과세 표준)
- 법인세 계산 흐름 (수익 → 비용 → 과세표준 → 세액)
- Python으로 기본 세율 계산 구현

### CH04: 재무 데이터 다루기
- 엑셀 파일에서 재무 데이터 읽기 (openpyxl)
- pandas로 손익계산서 데이터 가공
- 데이터 검증 및 오류 처리

### CH05: 세무조정 자동화
- 세무조정이란 (익금산입, 손금불산입 등)
- 주요 세무조정 항목 자동 계산
- 세무조정 명세서 데이터 구조 설계

### CH06: 법인세 계산 엔진 구현
- 과세표준 산출 로직
- 세율 적용 및 산출세액 계산
- 세액공제·감면 처리
- 계산 결과 데이터 모델

### CH07: Streamlit 웹 UI 구현
- Streamlit 기초 (레이아웃, 위젯)
- 데이터 입력 폼 구현
- 계산 결과 대시보드 (차트, 표)
- 파일 업로드/다운로드 기능

### CH08: 보고서 및 신고서 출력
- 법인세 계산 결과 엑셀 보고서 생성
- PDF 신고서 양식 출력 (fpdf2)
- 보고서 템플릿 관리

### CH09: 테스트와 검증
- pytest로 계산 로직 단위 테스트
- 경계값 테스트 (세율 구간 경계)
- 실제 사례 기반 통합 테스트

### CH10: 배포와 확장
- Streamlit Cloud 배포
- 다년도 비교 기능 추가
- 향후 확장 방향 (중간예납, 가산세 등)
