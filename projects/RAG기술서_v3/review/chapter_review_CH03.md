  [ChromaDB] 컬렉션 'ch03_rag_chunked' 생성 중...

[RAG 실험] 300자 청킹 적용
[검색된 관련 문서 — 상위 3개]
  [1] 출처: 인사팀 | 유사도: 0.575
  [2] 출처: 취업규칙 | 유사도: 0.462
  [3] 출처: 인사팀 | 유사도: 0.324

**화면 캡처:**
![STEP03 RAG 미리보기 실행 결과](../assets/CH03/step03_rag_preview.png)

**결과:** PASS (단, 주요 차이 사항 있음)

**발견된 차이점 및 문제점:**

1. **ChromaDB 텔레메트리 오류**: `stderr`에 `Failed to send telemetry event: capture() takes 1 positional argument but 3 were given` 오류가 반복 출력됩니다. 기능에는 영향 없으나 초보 독자에게 혼란을 줄 수 있습니다. chromadb 0.5.23 버전의 알려진 이슈입니다.

2. **청킹 효과 미미**: 챕터에서는 청킹 적용 시 유사도가 0.821 → 0.943으로 향상된다고 설명하지만, 실제 실행에서는 청킹 없음(0.575)과 300자 청킹(0.575)이 동일하게 나왔습니다. 문서 크기가 청크 크기(300자)보다 작아 청킹 효과가 없었습니다.

3. **챕터 예시 유사도 불일치**: 챕터에 제시된 0.821 / 0.943 수치와 실제 측정치 0.575가 다릅니다. 유사도 수치는 모델 버전과 텍스트에 따라 달라지므로 독자가 이를 미리 인지해야 합니다.

### STEP 4: RAG + DeepSeek R1 추론 능력 확인 (04_rag_reasoning.py)

**원고 지시:** `python src/04_rag_reasoning.py` 실행. 1분기 매출 데이터 3가지 추론 질문에 Chain-of-Thought 답변 확인

**실행 명령어:**
```bash
python src/04_rag_reasoning.py
```

**실제 출력 (요약):**
```
[실습 4] RAG + 추론 능력 확인 — 매출 데이터 분석

[데이터] 2025년 1분기 부서별 월별 매출 기록 7건

[추론 질문 1] 2025년 1분기 전체 매출 합계는 얼마인가요?
[검색된 관련 문서 — 상위 5개]
  [1] 요약보고서 | 유사도: 0.961
  [2] 01월 개발팀 | 유사도: 0.832
  ...
[LLM 추론 답변] \text{Total 매출} = 32M + 45M + 41M = 118,000,000원 (계산 오류 포함)

[추론 질문 2] 개발팀 월별 매출 증감 추이 분석
[LLM 추론 답변] 1월: 45M, 2월: 51M (3월 데이터 미포함, 부분 답변)

[추론 질문 3] 목표 달성률이 가장 높은 달
[LLM 추론 답변] 1월 (104.2% 달성률 참조, 계산 과정 포함)

[4단계 실습 완료 — 비교 요약]
  단계 1 (LLM 단독):         사내 정보 없음 → 환각 발생
  단계 2 (Context Injection): 문서 삽입 가능, 토큰 한계 존재
  단계 3 (RAG 미리보기):      관련 문서 검색 → 정확한 답변
  단계 4 (RAG + 추론):        데이터 검색 + 계산/분석 → 심화 답변
```

**화면 캡처:**
![STEP04 RAG 추론 실행 결과](../assets/CH03/step04_rag_reasoning.png)

**결과:** PASS (부분적 계산 오류 및 영어 혼재 있음)

## 6. 학생 한마디

> "4단계 실습 구조는 정말 잘 설계되어 있었습니다. 실패(환각) → 임시해결(Context Injection) → 성공(RAG)으로 이어지는 스토리텔링이 RAG의 필요성을 피부로 느끼게 해줬습니다. 다만 deepseek-r1:1.5b 모델을 사용하면 응답이 영어로 나와서 챕터 예시와 달라 처음에는 뭔가 잘못된 건지 헷갈렸고, Python 3.14에서는 의존성 설치 자체가 실패해서 당황했습니다. 이 두 가지만 보완되면 훌륭한 튜토리얼 챕터가 될 것입니다."

## 7. 개선 제안
