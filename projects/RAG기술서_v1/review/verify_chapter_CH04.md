  ```python
  app = FastAPI(

  )
  ```

- **실제 파일 (`examples/CH04_베이스시스템확보/app/main.py`, 17~28행)**:
  ```python
  app = FastAPI(
      title="RAG 기반 AI 업무 비서 — 베이스 CRUD API",
      description=(
          "AI 업무 비서 구축: RAG + MCP 실전 가이드 4장 베이스 시스템.\n\n"

      },

  ```

- **권장 조치**: 원고 코드를 실제 파일 내용에 맞춰 일치시키거나, "핵심 부분 발췌" 임을 독자에게 명시할 것.

#### 차이점 2 — `get_sales_summary` 함수 내 null 처리 로직

원고(343~364행)의 코드에서 `total_amount` 변환 로직이 단순 `float()` 처리만 보여주지만, 실제 파일(`sales.py` 62행)에는 null 대비 조건 처리가 추가되어 있습니다.

- **원고 코드**:
  ```python
  "total_amount": float(row.total_amount),
  ```

- **실제 파일 코드**:
  ```python
  "total_amount": float(row.total_amount) if row.total_amount is not None else 0.0,
  ```

- **영향 수준**: 낮음 — 실습 흐름 이해에는 지장 없으나 방어적 코딩 원칙과 불일치.
- **권장 조치**: 원고 코드에 null 처리 조건을 추가하거나 각주로 "실제 파일에는 null 방어 처리가 추가되어 있습니다"를 명시할 것.
