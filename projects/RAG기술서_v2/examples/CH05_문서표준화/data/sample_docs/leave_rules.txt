1. 연차 휴가

1.1 연차 발생 기준

연차 휴가는 근로기준법 제60조에 따라 아래와 같이 발생합니다.

입사 첫 해:
- 매월 개근 시 1일의 유급 휴가 발생 (최대 11일)
- 1년 근속 후 기본 15일 부여

입사 2년 차 이후:
- 기본 15일에 매 2년마다 1일 추가 (최대 25일)
- 예시: 3년 차 16일, 5년 차 17일, 7년 차 18일...

1.2 연차 사용 기간

- 연차는 해당 연도에 사용을 원칙으로 합니다.
- 미사용 연차는 다음 연도 1월 31일까지 이월 가능합니다.
- 이월 한도: 최대 5일 (초과분은 연차 보상금으로 지급)
- 연차 보상금 계산: 미사용 1일당 일 통상 임금의 100%

1.3 연차 사용 방법

- 1일 단위 사용 원칙
- 반차 사용 가능 (오전 반차: ~오후 1시, 오후 반차: 오후 1시~)
- 시간 단위 연차는 시행하지 않습니다.

2. 특별 휴가

2.1 경조사 휴가

| 경조 사유 | 휴가 일수 | 비고 |
|---------|---------|------|
| 본인 결혼 | 5일 | 유급 |
| 자녀 결혼 | 1일 | 유급 |
| 부모 회갑/칠순 | 1일 | 유급 |
| 배우자 출산 | 10일 | 유급 (법정 의무) |
| 부모/배우자 사망 | 5일 | 유급 |
| 조부모/형제 사망 | 3일 | 유급 |
| 자녀 사망 | 5일 | 유급 |

경조사 휴가는 해당 사유 발생일 기준 전후로 연속 사용해야 합니다.
경조사 증빙 서류(청첩장, 사망 진단서 등)를 인사팀에 제출해야 합니다.

2.2 생일 휴가

- 본인 생일이 포함된 주에 반차 1회 사용 가능
- 생일이 주말인 경우 해당 주 금요일 반차로 대체

2.3 리프레시 휴가

- 3년 근속 완료 시: 5일 추가 유급 휴가 (연차와 별개)
- 5년 근속 완료 시: 7일 추가 유급 휴가 + 50만 원 여행비 지원
- 7년 이상: 10일 추가 유급 휴가 + 100만 원 여행비 지원

================================================================

3. 병가 및 의료 휴가

3.1 단기 병가 (7일 이하)

- 연간 5일 유급 병가 제공 (연차 차감 없음)
- 5일 초과 시 연차에서 차감
- 3일 이상 병가 사용 시 의사 진단서 제출 요구 가능

3.2 장기 병가 (8일 이상)

- 의사 소견서 필수 제출
- 최대 90일 병가 허용 (유급 30일 + 무급 60일)
- 90일 초과 시 개별 상황에 따라 인사위원회 심의

3.3 업무 중 부상

- 산업재해 처리 원칙
- 요양 기간 중 평균 임금의 70% 지급 (산재보험)
- 산재 처리 불가 시 회사 지원 방안 개별 협의

================================================================

4. 육아 및 가족 돌봄 휴가

4.1 출산 휴가

- 출산 전후 90일 유급 휴가 (법정)
- 쌍둥이 이상: 120일
- 출산 전 최대 44일 선사용 가능

4.2 육아 휴직

- 자녀 만 8세 이하 또는 초등학교 2학년 이하
- 최대 1년 (부모 각각 1년씩, 총 2년)
- 첫 3개월: 통상임금의 80% 지급 (상한 150만 원)
- 이후 기간: 통상임금의 50% 지급 (상한 120만 원)

4.3 가족 돌봄 휴가

- 연간 최대 10일 (유급 3일 + 무급 7일)
- 대상: 조부모, 부모, 배우자, 자녀, 손자녀
- 한 번에 최대 3일 연속 사용 가능

4.4 난임 치료 휴가

- 연간 최대 3일 유급 휴가
- 인공 수정 또는 체외 수정 시 적용

================================================================

5. 휴가 신청 방법

5.1 사전 신청 원칙

연차 휴가는 원칙적으로 사용 3일 전 사전 신청합니다.
긴급 상황(갑작스러운 질병, 가족 긴급사항)은 당일 신청 허용.

5.2 신청 절차

단계 1: 인사 관리 시스템(HR Portal) 접속
단계 2: 휴가 신청 메뉴 선택
단계 3: 휴가 유형, 기간, 사유 입력
단계 4: 업무 인수인계 담당자 지정
단계 5: 팀장 승인 요청 (자동 알림 발송)
단계 6: 팀장 승인 완료 후 자동 처리

5.3 팀장 승인 기준

팀장은 다음 사유로 휴가를 반려할 수 있습니다.
- 동일 시기 팀 내 인원 과다 휴가 집중 시
- 마감 기한이 촉박한 중요 프로젝트 진행 중
- 반려 시 팀장은 대체 가능 일정 안내 의무

================================================================

6. 휴가 잔여 관리

6.1 잔여 휴가 확인

- HR Portal에서 실시간 잔여 휴가 일수 확인 가능
- 매월 1일 전월 사용 내역 이메일 발송

6.2 연말 잔여 휴가 처리

- 12월 15일까지 인사팀에서 잔여 연차 알림 발송
- 12월 31일 기준 미사용 연차 정산 처리
- 이월 또는 보상금 선택 (1월 10일까지 의사 표현)

6.3 퇴직 시 연차 정산

퇴직 시 미사용 연차는 퇴직일 기준으로 정산하여 마지막 급여와 함께 지급합니다.
