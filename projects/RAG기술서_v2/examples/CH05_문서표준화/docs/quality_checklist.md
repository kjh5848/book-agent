# 문서 품질 체크리스트 (RAG 입력 문서 선별 기준)

> 섹션 5.1 대응 자료 — GIGO(Garbage In, Garbage Out) 원칙에 따른 문서 선별 가이드

---

## 1. 왜 문서를 선별해야 하는가

RAG 시스템에서 검색 품질의 70%는 입력 문서의 품질이 결정합니다.
3,000페이지를 모두 넣으면 노이즈가 늘어나고 검색 정확도가 떨어집니다.
핵심 50개 문서를 선별하는 것이 전체 3,000페이지를 넣는 것보다 성능이 좋습니다.

---

## 2. 포함 기준 (Include)

아래 기준을 모두 충족하는 문서를 선별합니다.

| 항목 | 기준 | 이유 |
|------|------|------|
| 최신성 | 작성/수정일이 2년 이내 | 오래된 정보는 오답 유발 |
| 공식성 | 팀장 이상 승인된 공식 문서 | 비공식 메모는 신뢰도 낮음 |
| 완결성 | 섹션이 완결된 문서 | 미완성 문서는 부분 정보만 제공 |
| 가독성 | 표나 이미지 없이도 내용 이해 가능 | 표/이미지는 추출 과정에서 손실 발생 |
| 중복 없음 | 동일 내용을 다루는 문서가 없음 | 중복 문서는 검색 혼란 유발 |

---

## 3. 제외 기준 (Exclude)

아래 중 하나라도 해당하면 제외합니다.

- 2년 이상 업데이트가 없는 문서
- 특정 날짜나 이름이 포함된 회의록 (시점 종속적 정보)
- 스캔 이미지로만 구성된 PDF (텍스트 추출 불가)
- 개인 메모나 초안 문서 (공식 승인 미완료)
- 동일 내용의 버전이 여러 개인 경우 (최신 버전만 유지)

---

## 4. 우선순위 선별 매트릭스

| 문서 유형 | 우선순위 | 예시 |
|---------|---------|------|
| 정책/규정 | 최고 | 인사 정책, 보안 정책, 법규 |
| 프로세스/절차 | 높음 | 채용 절차, 휴가 신청 방법 |
| 가이드/매뉴얼 | 높음 | IT 가이드, 온보딩 매뉴얼 |
| FAQ | 보통 | 자주 묻는 질문 문서 |
| 회의록 | 낮음 | 특정 일자/인물 종속 |
| 개인 메모 | 제외 | 공식 승인 없음 |

---

## 5. 실습: 50개 문서 선별 워크플로우

```
전체 문서 (3,000p)
    ↓
[1단계] 공식 문서만 필터
    → 약 500개 문서
    ↓
[2단계] 2년 이내 문서만 필터
    → 약 150개 문서
    ↓
[3단계] 중복 제거 (최신 버전만 유지)
    → 약 80개 문서
    ↓
[4단계] 텍스트 추출 가능 여부 확인
    → 약 60개 문서
    ↓
[5단계] 팀 리뷰 및 최종 선별
    → 50개 핵심 문서
```

## 6. 체크리스트 양식

각 문서를 아래 양식으로 평가하십시오.

```
문서명: _______________
작성일: _______________
마지막 수정일: _______________
담당 부서: _______________

[ ] 2년 이내 작성/수정 문서인가?
[ ] 팀장 이상 승인된 공식 문서인가?
[ ] 내용이 완결되어 있는가?
[ ] 텍스트 추출이 가능한가? (스캔 이미지 아님)
[ ] 동일 내용의 최신 버전인가?

포함 결정: [ ] 포함 / [ ] 제외
제외 사유: _______________
```
