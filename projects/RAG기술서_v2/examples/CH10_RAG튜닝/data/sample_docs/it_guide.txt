# 커넥트HR IT 시스템 사용 가이드 v1.5

## 1. 계정 관리

### 1.1 계정 생성
- 신규 입사자 계정은 IT팀이 입사 전날까지 생성합니다.
- 초기 비밀번호는 입사 당일 IT팀에서 문자로 발송합니다.
- 첫 로그인 시 반드시 비밀번호를 변경해야 합니다.

### 1.2 비밀번호 정책
- 비밀번호는 영문 대소문자, 숫자, 특수문자를 포함하여 8자 이상이어야 합니다.
- 비밀번호는 90일마다 변경해야 합니다.
- 이전에 사용한 비밀번호 5개는 재사용할 수 없습니다.
- 5회 연속 로그인 실패 시 계정이 잠깁니다. IT팀(내선 1234)에 문의하십시오.

### 1.3 다중 인증(MFA)
- 모든 외부 접속(VPN, 재택근무)에는 MFA가 필수입니다.
- MFA 앱은 Google Authenticator 또는 Microsoft Authenticator를 사용합니다.
- MFA 설정은 IT Portal(it.connecthr.com)에서 진행합니다.

## 2. 업무 시스템

### 2.1 HR Portal
- 접속 주소: hr.connecthr.com
- 용도: 근태 관리, 급여 조회, 연차 신청, 인사 문서 발급
- 사용 가능 시간: 24시간 (유지보수 시간 제외)
- 모바일 앱: iOS/Android 지원

### 2.2 이메일 시스템
- 이메일 계정 형식: 이름@connecthr.com
- 저장 용량: 50GB (초과 시 IT팀 신청)
- 대용량 파일 전송: 10MB 초과 시 클라우드 링크 사용
- 외부 이메일 자동 전달 금지 (보안 정책)

### 2.3 협업 도구
- 사내 메신저: Slack (업무 공지, 팀 채널 운영)
- 화상 회의: Zoom (라이선스 계정 IT팀 신청)
- 문서 협업: Google Workspace (Docs, Sheets, Slides)
- 프로젝트 관리: Jira (개발팀 한정)

## 3. 보안 정책

### 3.1 데이터 보안
- 고객 데이터는 회사 승인 기기에서만 접근할 수 있습니다.
- 고객 정보를 개인 기기나 외부 클라우드에 저장하는 것은 금지됩니다.
- 화면 캡처 및 촬영은 보안 구역에서 금지됩니다.
- 데이터 유출 사고 발생 시 즉시 IT팀과 팀장에게 보고해야 합니다.

### 3.2 기기 보안
- 회사 지급 노트북에는 보안 소프트웨어가 설치되어 있습니다.
- 보안 소프트웨어를 임의로 비활성화하거나 삭제하면 안 됩니다.
- 자리를 비울 때는 반드시 화면 잠금을 설정해야 합니다 (단축키: Windows+L, Command+Control+Q).
- 분실 또는 도난 시 즉시 IT팀에 신고하십시오.

### 3.3 외부 접속 보안
- 재택 근무 시 VPN 접속이 필수입니다.
- VPN 클라이언트: Cisco AnyConnect (IT Portal에서 다운로드)
- 공용 Wi-Fi에서 업무 시스템 접속 시 반드시 VPN을 사용해야 합니다.

## 4. IT 지원

### 4.1 IT 지원 요청
- IT 헬프데스크: 내선 1234 (09:00~18:00)
- 이메일: it-support@connecthr.com
- 티켓 시스템: helpdesk.connecthr.com (24시간 접수)

### 4.2 장비 요청
- 신규 장비 또는 소프트웨어 라이선스는 팀장 승인 후 IT팀에 신청합니다.
- 장비 수령 소요 시간: 표준 장비 3일, 특수 장비 2주 이내
- 모든 회사 장비는 퇴직 시 반납해야 합니다.

### 4.3 긴급 지원
- 업무 불가 수준의 장애 발생 시 내선 1234로 즉시 연락합니다.
- 업무 시간 외 긴급 장애: 핸드폰 010-1234-5678 (당직자)
- 시스템 점검 시간: 매주 일요일 02:00~04:00
