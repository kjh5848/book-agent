1. VPN 접속 가이드

1.1 VPN 클라이언트 설치

회사 내부 시스템 접근을 위해 VPN 클라이언트(OpenVPN)를 설치해야 합니다.

macOS 설치:
App Store에서 "Tunnelblick" 검색 후 설치
인사팀으로부터 발급받은 .ovpn 설정 파일을 Tunnelblick에 드래그

Windows 설치:
https://openvpn.net/community-downloads/ 에서 설치 파일 다운로드
설치 후 .ovpn 파일을 C:\Program Files\OpenVPN\config 폴더에 복사

1.2 VPN 접속 방법

설치 완료 후 시스템 트레이 아이콘 우클릭 후 Connect 선택
ID: 회사 이메일 아이디 (@ 앞 부분)
비밀번호: 최초 발급 임시 비밀번호 (최초 접속 시 변경 필수)

1.3 VPN 사용 시 주의사항

재택근무 또는 외부 장소에서 업무 시스템 접속 시 반드시 VPN을 먼저 연결하십시오.
VPN 연결 없이 내부 시스템(GitLab, Jira 등) 접근이 불가합니다.

2. 보안 정책

2.1 비밀번호 정책

최소 12자 이상
영문 대문자, 소문자, 숫자, 특수문자 각 1개 이상 포함
90일마다 변경 필수 (만료 7일 전 알림 발송)
이전 5회 비밀번호 재사용 금지

2.2 화면 잠금 정책

자리 이탈 시 반드시 화면을 잠가야 합니다.
macOS: Command + Control + Q
Windows: Windows키 + L
5분 이상 입력 없으면 자동 잠금 (설정 변경 불가)

2.3 데이터 보안

고객 데이터를 개인 USB, 외부 클라우드(구글 드라이브 개인 계정 등)에 저장 금지
모든 고객 관련 파일은 회사 Notion 또는 Google Workspace에 저장
랩탑 분실 시 즉시 IT팀(02-1234-5678)에 신고 (원격 데이터 삭제 처리)

3. 업무 도구 사용법

3.1 Slack 채널 가이드

#general: 전사 공지 (메시지 발송 권한 제한, 읽기 전용)
#dev-team: 개발팀 채널
#hr-announcements: 인사 관련 공지
#random: 자유 대화

DM보다 채널 사용을 권장합니다. 업무 맥락이 팀 전체에 공유됩니다.

3.2 Notion 사용 가이드

팀 문서와 프로젝트 관리는 Notion을 사용합니다.
회사 Workspace: connecthr.notion.so
접속: 회사 Google 계정으로 SSO 로그인
페이지 생성 시 반드시 적절한 팀 스페이스 하위에 생성

3.3 GitHub (사내 GitLab) 사용 가이드

코드 버전 관리는 사내 GitLab(gitlab.connecthr.internal)을 사용합니다.
VPN 연결 필수
브랜치 전략: main, develop, feature/XXX
PR(Merge Request) 없이 main 브랜치 직접 push 금지

4. 장비 관리

4.1 지급 장비 목록

입사 시 아래 장비를 지급합니다.
노트북 1대 (macOS 또는 Windows 선택)
모니터 1대 (27인치)
키보드 및 마우스
헤드셋 (원격 미팅용)

4.2 장비 고장 및 수리

장비 이상 발생 시 IT 지원 채널(#it-support)에 요청합니다.
긴급 시: IT팀 직통 번호 내선 200번
수리 기간 중 대여 장비 제공 가능

4.3 소프트웨어 설치 정책

업무용 소프트웨어 설치는 IT팀 승인 후 진행합니다.
개인 라이선스 소프트웨어의 회사 장비 설치는 금지합니다.
오픈소스 소프트웨어는 라이선스 확인 후 사용 가능합니다.
